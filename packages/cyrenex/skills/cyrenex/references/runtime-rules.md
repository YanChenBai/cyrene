# Cyrene 运行规则

用于排查边界问题；常规接入优先看 SKILL.md 和 examples.md。

## 声明身份与图校验

- key 是不可变的非空字符串；同一声明重复注册幂等，不同声明在有效图中使用同 key 会报错。
- `use()` 整批验证入口后才登记；完整依赖图校验发生在首次解析、`init()` 或 `inspect()`。
- 普通输入、嵌套对象和普通 Promise 原样传入工厂，不被当作服务声明递归展开。
- `isRipple()` 识别当前库创建的声明。循环检测按运行时声明身份进行，而非 TypeScript 结构类型。
- 强依赖环在工厂执行前拒绝；lazy 的实际异步等待环在初始化时拒绝。

## 覆盖与可达性

- `override()` 保留原 key、可见范围和兼容的同步/异步返回契约；工厂、依赖和 lifetime 来自替身。
- 可以先 override 再 use。同一原声明最后一次覆盖生效，`override(original, original)` 恢复原实现。
- 只收集有效实现的依赖；原实现独有的依赖可能被裁剪。
- 覆盖目标必须在有效图中可达，包括不能被上层覆盖裁剪掉。
- 同一个替身不能占据多个节点，也不能同时作为其他入口或依赖节点。
- 原声明与当前替身都能定位该节点，已经换掉的旧替身不能。

## 解析、缓存与等待环

- `init()` 立即锁定配置，异步验证整张有效图，然后初始化所有可达 singleton，包括内部节点和 lazy 目标；以替身的 lifetime 为准，不额外预创建 transient。
- `init()` 返回 `Promise<void>`，并发及重复调用复用同一个 Promise，包括失败结果。独立分支并发，全部结束后报告失败，不自动回滚或重试。
- `dispose()` 等待已经接受的整批 `init()`，包括尚未启动的分支；关闭开始后的新 `init()` 调用返回拒绝的 Promise。工厂不能等待同一容器的 `init()`。

- `ripples` 的入口属性只读，服务实例本身不代理。单例并发解析共享初始化结果，失败也会缓存。
- 同步创建失败及无效入口直接抛错；异步创建失败拒绝 Promise。失败不会自动关闭容器。
- transient 每次属性读取、每个强依赖输入及每次 lazy.resolve 都重新执行工厂；异步尝试使用独立 Promise，失败后下次显式解析可重试。
- transient 工厂主动返回同一对象时不会复制它；可共享 singleton 依赖。
- 同一创建链中递归创建仍在初始化的声明会报错；就绪实例可以通过 lazy 创建同声明的另一个 transient 实例。
- 初始化期间，异步 lazy 句柄按句柄与目标实例复用 Promise 包装；其身份与公共入口 Promise 不同。
- 仅启动 lazy.resolve 不登记等待边；await、从异步工厂返回以及 then/catch/finally 链都登记，包括仅观察结果的回调。
- 消费者就绪后，句柄直接返回目标解析结果：singleton 复用，transient 新建。

## 清理与所有权

- 工厂返回时带 Symbol 清理协议的 owned 实例保留到关闭；按首次创建完成的逆序释放，`Symbol.asyncDispose` 优先。
- 所有权跟踪使用弱引用，不因资源表额外保留普通对象或 borrowed 实例；singleton 的解析缓存仍持有结果。
- 同一对象身份只清理一次，混用 owned / borrowed 声明会报错。
- 后来激活的 lazy 依赖与别名遵循实际首次完成顺序，不另按依赖拓扑重排。
- `dispose()` 幂等，先关闭新解析入口，等待已接受的初始化，再清理。清理失败后继续处理其他资源，最后聚合错误。
- transient 不提供每次调用后的释放或请求作用域。业务任务须由应用停止并等待，容器只等待初始化。

## 诊断

`formatGraph(app.inspect())` 用于展示有效图。快照的 `roots` 是显式入口，`nodes` 和 `edges` 包含完整有效图。
node 只有原 key 与状态，状态是该 key 最近一次初始化状态，不是并发 transient 实例的汇总。
`inspect()` 不锁定配置；配置变化会使缓存图失效。lazy 回调在构图时求值，因此必须稳定且无副作用。
